# What I’m building

Telugu language learning app for second generation children of immigrants to English-speaking countries who want to speak to loved ones and stay connected to their heritage.

## Core features

- Audio recording to transcription in Telugu or English to create vocabulary flashcards
- Vocabulary lookup using English or transliterated Telugu

## Tech stack

- SvelteKit, Drizzle, Neon (should be able to support APIs)
- Chat GPT-Realtime-Translate
- Wispr for audio transcription, if not already covered by GPT-Realtime-Translate

## Nice-to-haves

- Conjugation support (presented visually in tables with audio)
- Common Telugu phrases
